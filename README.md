A breathtaking, luxury-style, fully interactive Islamic wedding invitation website designed for the Nikah Ceremony of **Zoya Firdous** and **Musavvir Ameen**.

## 🌟 Highlights & Features

1. **Royal Islamic Aesthetic**:
   - Deep Royal Peacock Teal (`#031920`, `#072b35`, `#0b3947`), Soft Ivory & Pearl White, Celestial Light Blue accents, and Rich Champagne Metallic Gold.
